# Data Science with Visualization - Experiment 1

## Objective
Perform Exploratory Data Analysis (EDA) using the Iris dataset with Pandas.

## Dataset
Iris Dataset

## Tools Used
- Python
- Pandas
- Google Colab

## Analysis Performed
- Displayed first 5 rows using head()
- Checked dataset information using info()
- Generated summary statistics using describe()
- Checked missing values using isnull().sum()
